The Engineering Challenge & Constraints

In multi-channel alert systems (monitoring, financial anomalies, verification OTPs), standard synchronous HTTP calls fail when recipient services (SMTP servers, SMS gateways, APNS) experience transient latency spikes or throttling. A blocking request thread can exhaust backend connection pools within seconds.

The objective was to design a completely decoupled event ingestion and worker fanout pipeline that guarantees:

  • Strict Sub-Millisecond Ingestion: Ingest API endpoints must respond in under 12ms without waiting on downstream delivery.
  • Absolute Idempotency: Duplicate event emissions from upstream clients must never result in duplicate emails or SMS messages.
  • Dead-Letter Queue (DLQ) & Graceful Retry: Transient provider failures must back off exponentially before dropping to an inspection queue.

Critical Architectural Decisions & Trade-offs

DECISION // MESSAGE BROKER

Kafka Partitioning vs RabbitMQ

Selected Apache Kafka over RabbitMQ to leverage consumer group partition offsets. Partitioning by user tenant ID guarantees sequential ordering per recipient while enabling horizontal worker pool scaling without race conditions.

DECISION // IDEMPOTENCY

Redis Distributed Locks with Sliding TTL

Employed an atomic Redis SETNX with an automated 24-hour sliding TTL keyed to the SHA-256 hash of (recipient_id + template_id + payload_digest). If a duplicate event arrives, the gateway immediately returns HTTP 200 with an IDEMPOTENT_IGNORED status.

DECISION // RUNTIME

Go Goroutine Worker Pool vs Python Celery

Replaced legacy Celery workers with custom Go goroutine pools. Memory footprint decreased from 1.2GB per container to 68MB, and channel dispatch throughput increased by 4.2x with zero garbage collection pause impact.

DECISION // FAULT ISOLATION

Channel-Specific Dead-Letter Queues

If an external email SMTP provider triggers rate limits (HTTP 429), SMS and Push channels remain completely unaffected. Failing payloads are diverted to a dedicated retry topic with exponential jitter backoff.
